# Sternenhof 🐴

Ein Pferde-Abenteuer zum Rechnen und Lesen für die 2. Klasse.

- **Mathe:** Plus und Minus bis 50, passt sich automatisch an
- **Lesen:** einfache Wörter mit Silbenfarben, jedes Wort antippen und vorlesen lassen
- **Cozy:** Pferd putzen, Hufe auskratzen, satteln, Stall einrichten
- **Geschichte:** Kapitel 1 – Funke, das Fohlen, ist verschwunden …

Läuft im Browser auf Handy und Tablet, kann als App auf den Startbildschirm gelegt werden und funktioniert offline. Der Spielstand bleibt auf dem Gerät.

## Lokal testen

```bash
node dev-server.js
```

Dann <http://localhost:5173> öffnen (im WLAN über die angezeigte IP-Adresse).
